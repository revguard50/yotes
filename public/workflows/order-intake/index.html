COMMON QUESTIONS

What manufacturers usually want to know.

Does this replace our ERP?

No. The agent is designed to coordinate the work that happens before and around the ERP, then prepare or perform the approved handoff supported by the selected system and implementation scope.

Does the agent place orders without approval?

The human boundary is configured with you. Consequential actions can pause for a named reviewer, and exceptions can always be routed to a person.

What happens when customer part numbers do not match ours?

The first workflow defines the available mapping data, confidence rules, and exception path. Low-confidence or new mappings should be presented to a person rather than guessed through.

How do we know whether the ROI is real?

Use the public calculator as a directional model. Make it decision-ready by validating actual volume, touch time, error incidence, and achievable agent execution against a representative set of orders.
